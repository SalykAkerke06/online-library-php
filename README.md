# Online Library — Онлайн кітапхана жүйесі

## Жобаның мақсаты

PHP және MySQL технологияларын қолданып, пайдаланушыларға кітаптарды іздеуге, қарауға және таңдаулыларға сақтауға мүмкіндік беретін веб-қосымша әзірлеу.

## Негізгі функциялары

1. Пайдаланушыны тіркеу және жүйеге кіру.
2. Кітаптар каталогын көрсету.
3. Кітаптарды атауы немесе авторы бойынша іздеу.
4. Кітаптарды санат бойынша сүзу.
5. Таңдаулы кітаптарды сақтау.
6. Әкімші арқылы кітап қосу, өңдеу және өшіру.
7. Пайдаланушы деректерін тексеру және қорғау.

## Негізгі беттер

1-Басты бет

7-Әкімші панелі

## 9-апта. Пайдаланушы интерфейсін әзірлеу

**Жоба:** Онлайн кітапхана жүйесі

### Орындалған жұмыстар

1. HTML көмегімен басты бет, кітаптар тізімі, тіркелу және кіру беттері жасалды.
2. CSS арқылы сайттың дизайны безендірілді.
3. JavaScript арқылы кітаптарды іздеу функциясы қосылды.
4. Сайттың мобильді құрылғыларға бейімделуі тексерілді.
5. Басты бетке кітапхана туралы ақпарат және Footer қосылды.
6. Жоба файлдары GitHub репозиторийіне жүктелді.

### Жобаның қазіргі күйі

Шамамен 25%. Frontend интерфейсі дайын. PHP және MySQL функциялары келесі апталарда қосылады.

### Кездескен мәселелер

GitHub-пен байланыстыру және Git параметрлерін орнату кезінде қиындықтар болды. Мәселелер шешіліп, файлдар репозиторийге жүктелді.

### 10-аптаға жоспар

HTML беттерін PHP форматына көшіру, header және footer бөліктерін бөлу, формаларды PHP арқылы өңдеу.
