# Online Library — Онлайн кітапхана жүйесі

## Жобаның мақсаты

PHP және MySQL технологияларын қолданып, пайдаланушыларға кітаптарды іздеуге, қарауға және таңдаулыларға сақтауға мүмкіндік беретін веб-қосымша әзірлеу.

## Негізгі функциялары

1. Пайдаланушыны тіркеу және жүйеге кіру.
2. Кітаптар каталогын көрсету.
3. Кітаптарды атауы немесе авторы бойынша іздеу.
4. Кітаптарды санат бойынша сүзу.
5. Таңдаулы кітаптарды сақтау.
6. Әкімші арқылы кітап қосу, өңдеу және өшіру.
7. Пайдаланушы деректерін тексеру және қорғау.

# 10-апта. PHP негіздері және серверлік құрылым

### 1. Орындалған тапсырмалардың қысқаша сипаттамасы

# 12-АПТА БОЙЫНША ЕСЕП

**Жоба тақырыбы: Online Library System**

**Тақырып: CRUD операцияларын жүзеге асыру**

## 1. Орындалған тапсырмалардың қысқаша сипаттамасы

12-аптада Online Library System жобасында CRUD операцияларын жүзеге асыру жұмыстары орындалды. Негізгі мақсат кітапхана жүйесіндегі кітаптар туралы мәліметтерді қосу, көрсету, өңдеу және жою мүмкіндіктерін жасау болды.

Жұмыс барысында MySQL деректер қорындағы `online_library` базасына `books` кестесі құрылды. Кестеге кітаптың атауы, авторы, жанры және сипаттамасы енгізілді. Бастапқыда деректер қорына бірнеше кітап туралы мәлімет қосылды.

PHP тілінде PDO арқылы деректер қорымен байланыс орнатылып, кітаптарды басқаруға арналған жеке файлдар жасалды.

Орындалған негізгі жұмыстар:

**1. Create – жаңа кітап қосу**

`add_book.php` файлы құрылды. Сайттағы арнайы форма арқылы жаңа кітаптың атауын, авторын, жанрын және сипаттамасын енгізу мүмкіндігі жасалды. Енгізілген мәліметтер MySQL деректер қорына сақталады.

**2. Read – кітаптарды көрсету**

`books.php` файлы жаңартылды. Кітаптар PHP массивінен емес, MySQL деректер қорынан алынады. Кітаптар каталогта карточкалар түрінде көрсетіледі. Іздеу функциясы да сақталды.

**3. Update – кітап мәліметтерін өңдеу**

`edit_book.php` файлы құрылды. Осы файл арқылы кітаптың атауын, авторын, жанрын және сипаттамасын өзгерту мүмкіндігі енгізілді. Өзгертілген мәліметтер деректер қорында жаңартылады.

**4. Delete – кітаптарды жою**

`delete_book.php` файлы құрылды. Әр кітаптың карточкасына жою батырмасы қосылды. Батырманы басқан кезде растау терезесі шығады. Расталғаннан кейін таңдалған кітап деректер қорынан жойылады.

## 2. SQL инъекциясынан қорғау

Деректер қорымен жұмыс істеу кезінде SQL инъекциясынан қорғану үшін PDO арқылы дайындалған сұраныстар (Prepared Statements) қолданылды.

PHP файлдарында `prepare()` және `execute()` әдістері пайдаланылды.

Мысалы:

```php
$stmt = $pdo->prepare(
    "DELETE FROM books WHERE id = :id"
);

$stmt->execute([':id' => $id]);
```

Бұл әдіс қолданушы енгізген мәліметтерді SQL сұранысының орындалатын кодынан бөлек өңдеуге көмектеседі.

## 4. Кездескен мәселелер және олардың шешімдері

Кітаптарды қосу, өзгерту және жою үшін жеке PHP файлдары құрылды. Әр функцияның дұрыс жұмыс істеуі браузер арқылы тексерілді.
