# Online Library — Онлайн кітапхана жүйесі

## Жобаның мақсаты

PHP және MySQL технологияларын қолданып, пайдаланушыларға кітаптарды іздеуге, қарауға және таңдаулыларға сақтауға мүмкіндік беретін веб-қосымша әзірлеу.

## Негізгі функциялары

1. Пайдаланушыны тіркеу және жүйеге кіру.
2. Кітаптар каталогын көрсету.
3. Кітаптарды атауы немесе авторы бойынша іздеу.
4. Кітаптарды санат бойынша сүзу.
5. Таңдаулы кітаптарды сақтау.
6. Әкімші арқылы кітап қосу, өңдеу және өшіру.
7. Пайдаланушы деректерін тексеру және қорғау.

# 10-АПТА ЕСЕБІ

**Жоба тақырыбы: Онлайн кітапхана жүйесі**

**Тақырыбы: PHP негіздері және серверлік құрылым**

### 1. Жұмыстың мақсаты

Жобаның HTML беттерін PHP форматына көшіру, PHP тілінің негізгі мүмкіндіктерін пайдалану, қайталанатын бөліктерді `include` арқылы біріктіру және HTML формаларын сервер жағында өңдеу.

### 2. Орындалған жұмыстар

**2.1. HTML беттерін PHP форматына көшіру**

Жобаның негізгі беттері PHP форматына ауыстырылды:

- index.php – басты бет;
- books.php – кітаптар тізімі;
- login.php – жүйеге кіру;
- register.php – пайдаланушыны тіркеу;
- id_student.php – студенттер бөлімі.

**2.2. Қайталанатын бөліктерді бөлу**

Ортақ элементтерді жеке файлдарға шығардым:

- header.php – сайттың жоғарғы бөлігі және навигация мәзірі;
- footer.php – сайттың төменгі бөлігі.

Бұл файлдар басқа PHP беттеріне `include` командасы арқылы қосылды.

**2.3. POST әдісі арқылы формаларды өңдеу**

Тіркелу және жүйеге кіру формалары `POST` әдісімен өңделді.

Тіркелу кезінде:
- Аты-жөнінің бос болмауы;
- Email форматының дұрыстығы;
- Телефон нөмірінің форматы;
- Құпиясөздің кемінде 8 таңбадан тұруы тексерілді.

Жүйеге кіру кезінде Email және құпиясөздің енгізілуі тексерілді.

**2.4. GET әдісі арқылы кітаптарды іздеу**

`books.php` бетінде кітаптарды іздеу функциясы жасалды. Пайдаланушы кітаптың атауын, авторын немесе жанрын енгізіп, іздеу нәтижесін алады. Іздеу нәтижесі болмаса, тиісті хабарлама көрсетіледі.

**2.5. Серверлік тексеру**

PHP кодтары арқылы енгізілген мәліметтер сервер жағында тексерілді. Қате мәлімет енгізілген жағдайда ескерту хабарламалары, ал дұрыс мәлімет енгізілгенде сәтті тексерілгені туралы хабарлама көрсетілді.

**2.6. Жобаны серверде іске қосу**

XAMPP бағдарламасы пайдаланылды. Apache сервері іске қосылып, жоба браузерде `http://localhost/online-library-php/` мекенжайы арқылы тексерілді.

### 3. Жұмыс нәтижесі

10-аптада PHP форматындағы беттер құрылды. Ортақ бөліктер `include` арқылы біріктірілді. POST және GET әдістері қолданылды. Тіркелу, кіру және кітап іздеу формаларының серверлік тексерілуі орындалды.

### 4. Қорытынды

Осы аптада PHP тілінің негізгі мүмкіндіктерімен таныстым. HTML формаларын сервер жағында өңдеуді, `$_POST`, `$_GET` айнымалыларын және `include` командасын қолдануды үйрендім. Жоба PHP ортасында іске қосылып, негізгі функциялары тексерілді.

**Ескерту:** MySQL дерекқорына қосылу және пайдаланушылар мәліметтерін сақтау келесі аптада орындалады.
