# Online Library — Онлайн кітапхана жүйесі

## Жобаның мақсаты
PHP және MySQL технологияларын қолданып, пайдаланушыларға кітаптарды іздеуге, қарауға және таңдаулыларға сақтауға мүмкіндік беретін веб-қосымша әзірлеу.

## Негізгі функциялары
1. Пайдаланушыны тіркеу және жүйеге кіру.
2. Кітаптар каталогын көрсету.
3. Кітаптарды атауы немесе авторы бойынша іздеу.
4. Кітаптарды санат бойынша сүзу.
5. Таңдаулы кітаптарды сақтау.
6. Әкімші арқылы кітап қосу, өңдеу және өшіру.
7. Пайдаланушы деректерін тексеру және қорғау.

## Негізгі беттер
1-Басты бет
2-Тіркелу беті
3-Кіру беті
4-Кітаптар каталогы
5-Кітап туралы толық ақпарат
6-Таңдаулы кітаптар
7-Әкімші панелі

## Қолданылатын технологиялар
1-HTML
2-CSS
3-JavaScript
4-PHP
5-MySQL
6-XAMPP
7-GitHub

## Дерекқор кестелері
1-users — пайдаланушылар
2-books — кітаптар
3-categories — кітап санаттары
4-favorites — таңдаулы кітаптар

## Жоба кезеңдері
1-8-апта: жоспарлау және GitHub репозиторийін құру.
2-9-апта: интерфейс жасау.
3-10-апта: PHP құрылымын дайындау.
4-11-апта: MySQL және тіркелу жүйесі.
5-12-апта: CRUD операциялары.
6-13-апта: іздеу, сүзу және сұрыптау.
7-14-апта: қосымша функциялар және қауіпсіздік.
8-15-апта: тестілеу, хостинг және қорғау.
