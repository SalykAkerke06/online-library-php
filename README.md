# Online Library — Онлайн кітапхана жүйесі

## Жобаның мақсаты

PHP және MySQL технологияларын қолданып, пайдаланушыларға кітаптарды іздеуге, қарауға және таңдаулыларға сақтауға мүмкіндік беретін веб-қосымша әзірлеу.

## Негізгі функциялары

1. Пайдаланушыны тіркеу және жүйеге кіру.
2. Кітаптар каталогын көрсету.
3. Кітаптарды атауы немесе авторы бойынша іздеу.
4. Кітаптарды санат бойынша сүзу.
5. Таңдаулы кітаптарды сақтау.
6. Әкімші арқылы кітап қосу, өңдеу және өшіру.
7. Пайдаланушы деректерін тексеру және қорғау.

# 9-апта. Пайдаланушы интерфейсін әзірлеу

### 1. Орындалған тапсырмалардың қысқаша сипаттамасы

- HTML арқылы басты бет, кітаптар тізімі, тіркелу және кіру беттері жасадым.
- CSS көмегімен сайттың дизайны безендірдім.
- JavaScript арқылы кітаптарды іздеу функциясы қостым.
- Сайттың мобильді құрылғыларға бейімделуі тексердім.
- Басты бетке кітапхана туралы ақпарат және Footer қостым.
- Жоба файлдары GitHub репозиторийіне жүктедім.

### 2. Жобаның қазіргі күйі

Жобаның орындалу деңгейі: 25%.

Негізгі интерфейс дайындадым. HTML, CSS және JavaScript файлдары жасадым. PHP және MySQL функциялары әлі қосылған жоқ.

### 3. Кездескен мәселелер және олардың шешімдері

GitHub репозиторийін байланыстыру және Git параметрлерін орнату кезінде қиындықтар кездесті. GitHub арқылы файлдарды жүктеу және коммит жасау жолдары үйреніп, мәселе шешімін таптым.

### 4. Келесі аптаға жоспар

- HTML беттерін PHP форматына көшіру.
- Header және Footer бөліктерін жеке файлдарға бөлу.
- Include командасын қолдану.
- Формаларды POST және GET әдістері арқылы өңдеу.
- PHP арқылы енгізілген мәліметтерді тексеру.

# 10-апта. PHP негіздері және серверлік құрылым

### 1. Орындалған тапсырмалардың қысқаша сипаттамасы

- HTML беттері PHP форматына көшірдім.
- index.php, books.php, login.php, register.php және id_student.php файлдары жасадым.
- header.php және footer.php файлдары құрадым.
- Include командасы арқылы ортақ бөліктер басқа беттерге қостым.
- Тіркелу және кіру формалары POST әдісімен өңдедім.
- Кітаптарды іздеу GET әдісі арқылы орындадым.
- Email, телефон нөмірі және құпиясөзді тексеру функциялары қостым.
- XAMPP бағдарламасындағы Apache сервері арқылы жоба іске қостым.

### 2. Жобаның қазіргі күйі

Жобаның орындалу деңгейі: 35%.

PHP беттері жасадым. Тіркелу, кіру және кітап іздеу формаларының серверлік тексеруі жұмыс істеп тұр. MySQL дерекқорымен байланыс әлі орнатқан жоқпын.

### 3. Кездескен мәселелер және олардың шешімдері

- PHP беттерін іске қосу кезінде XAMPP серверін баптау қажет болды. Apache серверін қосып ары қарай жұмысымды жалғастырдым.
- Формаларды тексеру кезінде Email, телефон нөмірі және құпиясөз форматтарына қатысты қателер кездесті. PHP арқылы серверлік тексерулер қостым.
- HTML сілтемелерін PHP беттеріне сәйкестендіру қажет болды. Навигация сілтемелерін жаңартым.

### 4. Келесі аптаға жоспар

- MySQL дерекқорын құру.
- PDO арқылы PHP мен MySQL байланысын орнату.
- users кестесін құру.
- Тіркелген пайдаланушылардың мәліметтерін дерекқорға сақтау.
- Құпиясөзді password_hash() арқылы қорғау.
- Жүйеге кіру функциясын дерекқормен байланыстыру.

### 4. Қорытынды

Осы аптада PHP тілінің негізгі мүмкіндіктерімен таныстым. HTML формаларын сервер жағында өңдеуді, `$_POST`, `$_GET` айнымалыларын және `include` командасын қолдануды үйрендім. Жоба PHP ортасында іске қосылып, негізгі функциялары тексерілді.

**Ескерту:** MySQL дерекқорына қосылу және пайдаланушылар мәліметтерін сақтау келесі аптада орындалады.
